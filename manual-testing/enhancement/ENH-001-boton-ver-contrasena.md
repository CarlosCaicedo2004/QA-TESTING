# MEJ-001: Falta botón para mostrar/ocultar la contraseña en el login

## Tipo
Mejora de usabilidad (no es un defecto funcional)

## Descripción
El campo de contraseña no ofrece un ícono de ojo para ver lo que se escribe.

## Dónde se observó
Página de login, caso TC-001

## Impacto
El usuario no puede verificar lo que escribió, lo que puede causar intentos fallidos por errores de tipeo, sobre todo en móvil.

## Sugerencia
Agregar un ícono de ojo junto al campo que alterne entre mostrar y ocultar la contraseña.

## Severidad / Prioridad
Baja / Baja
