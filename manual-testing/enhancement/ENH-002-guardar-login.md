# MEJ-002: No existe opción para recordar la sesión o las credenciales

## Tipo
Mejora de usabilidad (no es un defecto funcional)

## Descripción
La página de login no ofrece una opción tipo "Recordarme" para mantener la sesión o guardar el usuario.

## Dónde se observó
Página de login, casos TC-001 y TC-006

## Impacto
El usuario tiene que escribir sus credenciales completas en cada visita.

## Sugerencia
Agregar una casilla "Recordarme" que conserve la sesión o el usuario de forma segura.

## Severidad / Prioridad
Baja / Baja
