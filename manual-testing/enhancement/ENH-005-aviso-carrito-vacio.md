# MEJ-005: No se muestra un aviso cuando el carrito está vacío

## Tipo
Mejora de usabilidad (no es un defecto funcional)

## Descripción
Al abrir el carrito sin productos, la página muestra la lista vacía sin ningún mensaje.

## Dónde se observó
Página del carrito, caso TC-017

## Impacto
El usuario no recibe indicación clara de que el carrito está vacío ni de qué hacer a continuación.

## Sugerencia
Mostrar un mensaje como "Tu carrito está vacío" con un botón visible para volver al catálogo.

## Severidad / Prioridad
Baja / Baja
