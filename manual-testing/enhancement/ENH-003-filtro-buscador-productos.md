# MEJ-003: Falta filtro por categoría o buscador en el inventario

## Tipo
Mejora de usabilidad (no es un defecto funcional)

## Descripción
El inventario solo permite ordenar los productos por nombre o precio. No hay forma de filtrarlos por categoría ni de buscar por nombre.

## Dónde se observó
Página de inventario, caso TC-007

## Impacto
Con un catálogo más grande, el usuario tendría que recorrer todo el listado para encontrar lo que necesita.

## Sugerencia
Agregar filtros (categoría, rango de precio) o una barra de búsqueda sobre el listado.

## Severidad / Prioridad
Baja / Baja
